# 1 线性方程组

## 1.1 线性方程组

线性方程组的解有三种情况：

1. 无解
2. 有唯一解
3. 有无穷多解

若线性方程组有一个解或无穷多个解，则称为相容，反之称为不相容。

由方程组系数组成的矩阵称为**系数矩阵**，由方程组系数和常量组成的矩阵称为**增广矩阵**。

## 1.2 阶梯形矩阵

**阶梯形矩阵**有以下三个性质：

1. 所有非零行都在零行之上。
2. 每一行的先导元素所在的列位于前一行先导元素的右边。
3. 先导元素所在列下方的元素都是零

若还满足以下性质，则称为**简化阶梯形矩阵**

1. 非零行的先导元素是1。
2. 先导元素1是该元素所在列的唯一非零元素。

定理：

1. 一个矩阵只能化为唯一的简化阶梯形矩阵。
2. 线性方程组相容的充要条件是增广矩阵的最右列不是主元列。

定义：矩阵中的**主元**位置是它的简化阶梯形矩阵中先导元素1的位置，**主元列**是主元位置的列。

求解线性方程组：

将线性方程组的增广矩阵化为简化阶梯形矩阵，若最右列是主元列，则说明线性方程组不相容，即无解，反之相容，有解。接着判断是否存在**自由变量**，不存在则说明有唯一解，存在则说明有无穷解。

## 1.3 向量方程

仅含一列的矩阵称为**列向量**，简称**向量**。

给定向量A，B，C和标量X，Y。存在C=XA+YB。那么称向量C是A和B的线性组合。几何场景中，向量C位于向量AB组成的平面中。

## 1.5 线性方程组的解集

**齐次线性方程组**：Ax = 0

- A是系数矩阵
- x是未知数列向量
- 0是零向量

特点：

1. 解的存在性：齐次线性方程组至少有一个解，即x = 0，这个解称为**平凡解**。存在**非平凡解**当且仅当方程组至少有一个自由变量。
2. 几何意义：齐次线性方程组的解集构成一个向量空间，称为解空间。这个空间的维度等于齐次线性方程组的自由变量个数。

## 1.8 线性变换简介

定义：若

1. 对T的定义域中一切u,v，T(u + v) = T(u) + T(v)
2. 对于T的定义域中一切u和标量c，T(cu) = cT(u)

则变换（或映射）T称为**线性**的。
