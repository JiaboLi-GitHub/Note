# 1 FreeType 字形约定

**字体家族**是一组风格统一，设计理念一致，但细节形式有差异的字体的总称。**字体外观**是字体家族中某个具体呈现形式。

因设备 dpi（每英寸像素量） 不同，字体尺寸常用 “点” 描述（避免像素的设备依赖性）。数字排版中：**1 点 = 1/72 英寸**，对应像素数为 **dpi × 1/72**（字体像素尺寸 = 点值 ×dpi÷72）。

## 2.2 PDF文件结构

PDF文件结构指PDF物理组织形式。

### 2.2.1 文件头

标识PDF文件的版本

### 2.2.2 文件体

包含所有PDF对象，每个对象以obj和endobj标记包裹，并有唯一编号。如（1 0 obj）。

### 2.2.3 交叉引用表

记录文件中各个对象的存储位置和状态。

```
xref
<起始对象编号> <对象数量>
<偏移量> <生成号> <状态标志>
```

- 偏移量：对象在文件中的起始字节位置。
- 生成号：0000代表初始版本，65535表示删除。
- 状态标志：n表示对象有效，可被引用；f表示对象已删除或空闲。

```
xref
0 1
0000000000 65535 f  % 对象0：偏移量0，生成号65535（删除），保留条目

1 6
0000000009 00000 n  % 对象1：偏移量9，初始版本，有效
0000000060 00000 n  % 对象2：偏移量60，初始版本，有效
0000000145 00000 n  % 对象3：偏移量145，初始版本，有效
0000000228 00000 n  % 对象4：偏移量228，初始版本，有效
0000000333 00000 n  % 对象5：偏移量333，初始版本，有效
0000000424 00000 n  % 对象6：偏移量424，初始版本，有效
```

### 2.2.4 文件尾

包含交叉引用表的位置、根对象（Root）的引用等关键信息，用于文件解析的入口。

```
trailer
 
<<
 
/Size 7 % 交叉引用表总条目数
 
/Root 6 0 R % 根对象（ID=6）
 
>>
 
startxref
 
488 % 交叉引用表起始偏移量
 
%%EOF % 文件结束标记
```

### 2.2.5 可选部分

加密信息、增量更新等，用于扩展文件功能。

## 2.3 PDF文档结构

PDF文档结构指PDF文档内容的逻辑组织和语义关系。建议使用PDFXplorer工具进行分析。

### 2.3.1 Trailer字典

尾字典：

| 键    | 值类型       | 意义     |
| ----- | ------------ | -------- |
| /Root | 间接引用字典 | 文件目录 |
| /Info | 间接引用字典 | 文档信息 |

### 2.3.2 Info

文档信息字典：

| 键            | 值类型 | 意义                                                 |
| ------------- | ------ | ---------------------------------------------------- |
| /Title        | 字符串 | 该文件的标题。请注意，这与第一页上显示的任何标题无关 |
| /Author       | 字符串 | 文档作者的姓名                                       |
| /CreationDate | 字符串 | 文档创建的日期                                       |
| /ModDate      | 字符串 | 上次修改文档的日期                                   |

### 2.3.3 Root

文档目录字典：

| 键      | 值类型       | 意义             |
| ------- | ------------ | ---------------- |
| /Type*  | name         | 必须是/Catalog   |
| /Pages* | 间接引用字典 | 页面树的根节点。 |
